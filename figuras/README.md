# Figuras do projeto

Gráficos derivados dos resultados agregados da ANP/LPC, diesel S10 em DF/GO, primeiro semestre de 2026. Gerados por `scripts/visualizar.py`.

- `01_evolucao.png`: medianas semanais de Brasília, Goiânia e Anápolis.
- `02_oportunidade.png`: diferença relativa média mediana/P25, somente localidades com pelo menos 12 semanas elegíveis.
- `03_cenario.png`: diferença de gasto hipotética para 5.000 litros por semana.

As figuras não representam economia realizada. A interpretação e as limitações estão no README principal.
